# Employee Task Management System

A **Django web application** to manage employees and their tasks efficiently. This project demonstrates skills in **Python, Django, database management, and web development**.

---

## 🌐 Live Demo
[View Live Project](https://employee-task-management-eibe.onrender.com/)

---

## 🚀 Features

- Add, edit, and delete employee records  
- Assign tasks and track progress  
- Dashboard analytics of employees and tasks  
- Import employee data via Excel files  
- Responsive UI for desktop and mobile

---

## 🛠 Technologies Used

- **Backend:** Python 3.13, Django 5.2.7  
- **Database:** SQLite  
- **Frontend:** HTML, CSS (in templates)  
- **Deployment:** Render  
- **Version Control:** Git & GitHub
